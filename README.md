# Paint — Desktop Drawing Application

A desktop drawing application developed in C# using Windows Forms. The application provides a graphical interface for drawing, working with colors and shapes, and managing image files.

## Features

- **Freehand Drawing** — draw freely using the pencil tool.
- **Shape Tools** — draw lines, rectangles, and ellipses.
- **Color Selection** — choose colors for drawing.
- **Adjustable Stroke Width** — select different line thicknesses.
- **Fill Tool** — fill connected areas with a selected color.
- **Image File Operations** — create a new canvas, open images, and save drawings.

## Technologies

- C#
- Windows Forms
- Visual Studio

## Getting Started

1. Clone or download this repository.
2. Open `Paint.sln` in Visual Studio.
3. Build the solution.
4. Run the application.
